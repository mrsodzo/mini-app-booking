Mini App для записи на услуги (Telegram Web App)

== Цель проекта ==

Разработать работающий прототип Telegram-бота с встроенным Mini App (Web App) для записи клиентов на услуги. Проект делается для портфолио, чтобы показывать заказчикам как пример реализации Mini App в Telegram.

== Функциональные требования ==

=== 1. Telegram-бот ===

1.1 Команда /start
- Приветственное сообщение
- Кнопка "Записаться" с переходом в Mini App (web_app)
- Кнопка "Мои записи" — показывает список записей пользователя

1.2 Обработка данных из Mini App
- Бот получает данные из Mini App (выбранная услуга, дата, время, имя, телефон)
- Сохраняет запись в БД
- Отправляет подтверждение пользователю (текст с деталями записи)
- Отправляет уведомление администратору (в отдельный чат или самому себе)

1.3 Команда /admin (для владельца)
- Просмотр всех записей
- Отметка записи как выполненной / отменённой

=== 2. Mini App (Web App) ===

2.1 Главный экран
- Название компании / услуги (заглушка, например "Beauty Studio")
- Список услуг (3–5 штук): название, цена, длительность
- Выбор услуги → переход к выбору времени

2.2 Выбор даты и времени
- Доступные даты: сегодня, завтра, послезавтра
- Доступные слоты: 10:00, 12:00, 14:00, 16:00, 18:00 (захардкожены для демо)
- При выборе слота — он становится недоступным для других пользователей (имитация занятости)

2.3 Форма записи
- Имя (текстовое поле)
- Телефон (текстовое поле)
- Кнопка "Подтвердить запись"

2.4 Экран успеха
- Спасибо, вы записаны!
- Детали записи (услуга, дата, время)
- Кнопка "Вернуться в бот" (закрывает Mini App)

=== 3. Маркетинговый блок (конкурс/акция) ===

3.1 В боте:
- Кнопка "Участвовать в конкурсе" (в меню после /start)
- При нажатии — переход в Mini App на страницу конкурса

3.2 В Mini App:
- Страница с описанием конкурса: "Угадай загадку и выиграй скидку 20%"
- Поле для ввода ответа
- Кнопка "Отправить ответ"
- После отправки: "Спасибо за участие! Результаты объявим завтра."

3.3 В боте:
- При отправке ответа — бот сохраняет его в БД
- Бот отправляет уведомление администратору о новом участнике

== Технический стек ==

Telegram-бот: Python, aiogram 3.x
Mini App: HTML, CSS, JavaScript (один файл)
База данных: SQLite (через aiosqlite)
Хостинг бота: Render.com / VPS
Хостинг Mini App: Netlify (бесплатный)
Переменные окружения: .env (python-dotenv)

=== Модели данных ===

User
- id (int, primary key)
- telegram_id (int, unique)
- username (str, nullable)
- created_at (datetime)

Booking
- id (int, primary key)
- user_id (int, foreign key → User)
- service (str) — название услуги
- date (str) — дата записи
- time (str) — время записи
- client_name (str)
- client_phone (str)
- status (str) — 'new', 'confirmed', 'completed', 'cancelled'
- created_at (datetime)

ContestEntry
- id (int, primary key)
- user_id (int, foreign key → User)
- answer (str)
- created_at (datetime)

=== Взаимодействие бота и Mini App ===

1. Пользователь нажимает кнопку в боте → открывается Mini App (через web_app)
2. Mini App отправляет данные в бот через window.Telegram.WebApp.sendData()
3. Бот обрабатывает данные и сохраняет в БД
4. Бот отправляет подтверждение пользователю

=== Переменные окружения (.env.example) ===

BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
DATABASE_URL=sqlite:///./data/bot.db
ADMIN_CHAT_ID=123456789
WEBAPP_URL=https://your-netlify-app.netlify.app

=== Критерии приёмки ===

1. Бот запускается и отвечает на /start
2. При нажатии "Записаться" открывается Mini App
3. В Mini App можно выбрать услугу, дату, время
4. После заполнения формы — данные уходят в бот
5. Бот присылает подтверждение пользователю
6. Бот присылает уведомление администратору
7. При повторном выборе занятого слота — он недоступен (имитация)
8. Конкурс: можно ввести ответ, он сохраняется в БД
9. /admin — показывает список записей
10. Код задеплоен на Render (бот) и Netlify (Mini App)

=== Инструкция по запуску ===

1. Клонировать репозиторий
2. Создать .env из .env.example
3. Установить зависимости: pip install -r requirements.txt
4. Запустить бота: python main.py
5. Mini App залить на Netlify (через drag-and-drop папки webapp/)

=== Деплой Mini App на Netlify ===

1. Перейти на netlify.com
2. Перетащить папку webapp/ в окно браузера
3. Получить ссылку вида https://название.netlify.app
4. Вставить эту ссылку в .env как WEBAPP_URL
5. В боте указать эту ссылку в кнопке web_app
